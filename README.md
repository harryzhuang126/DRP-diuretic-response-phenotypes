# DRP-diuretic-response-phenotypes
R scripts for diuretic response phenotype identification among ICU patients based on MIMIC-IV database.

## Description
This repository contains analysis scripts, including phenotype definition, descriptive statistics, regression, survival analysis and visualization code.
**No raw MIMIC-IV patient data is included.**

## Keywords
MIMIC-IV, diuretic response, phenotype, critical care, ICU
